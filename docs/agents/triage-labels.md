# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| Needs evaluation | needs-triage | Maintainer must evaluate the incoming request |
| Needs information | needs-info | Waiting for missing information |
| Ready for agent | ready-for-agent | Specified and ready for autonomous implementation |
| Ready for human | ready-for-human | Requires human implementation |
| Not proceeding | wontfix | Will not be actioned |

Use these for incoming request triage. Agent-created implementation tickets use their own workflow status.
